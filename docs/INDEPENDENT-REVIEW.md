# 1.0.1 独立只读质检与修复记录

日期：2026-11-03。基线：1.0.0，提交 d90911c872e7dc3a6345e3c299dd5ec2787e1731。

按用户要求，本轮新设独立审查代理先只读检查，再由原实施代理修改。独立审查代理及其审查子代理未创建、修改任何文件；本说明由原实施代理根据其报告编写。所有修改、测试文件和文档更新均由原实施代理完成。全部复现使用合成输入，没有使用参考材料中的真实患者或医生信息。

| 同采样时点冲突的甲状腺检验因录入顺序产生不同解释 | 同一项目同采样时点出现冲突即暂停组合解释；完全相同的重复结果不引入冲突 |

| 查房意见、自定义事项、备注等被静默截断 | 输入和去标识后的文本均作显式上限检查，拒绝超限，不截断接受的内容；界面同步设置长度限制 |
| 补充去标识词超过数量或长度限制后被静默忽略 | 最多 200 个不同词，每词最多 200 字符；超限明确报错，每个接受的词都应用 |

## 修复复核追加发现

独立审查随后又发现 8 个边界问题，仍由原实施代理修复并增加回归：

- 浏览器可能输出 1–2 位小数秒：接受 1–3 位并按实际毫秒归一化。
- α-羟丁酸脱氢酶误匹配酮体：限定 β/3-羟丁酸名称，排除该酶。
- `COVID：阴性` 的 ID 后缀被当成身份标签：要求标签起始边界，保留结果。
- 陪诊者的明确年龄性别先于患者字段时抢占结果：患者专属标签优先，普通字段限于患者头部行。
- `[已移除]` 后追加姓名绕过清理：仅完整占位符可豁免，附加内容仍清理。
- 全空格采样条件被当成已填写：统一去除首尾空白，缺失条件不作趋势比较。
- 替换词扩大文本后生成不能导出的病例：接受前校验转换后的长度，失败时保留之前病例；去标识占位符不被重复扩展。

- 加入标签边界后，嵌套在一般情况或括号中的姓名标签遗漏：补充冒号及开括号边界，保留对 COVID 的保护。

## 验证与边界

最终独立代理的 6 项针对性断言及 62 项自动化测试通过，已报告的问题在最终针对性复核中未再复现。

可复现的自动化检查见 tests/engine.test.mjs 和 tests/audit-regressions.test.mjs。界面验证和最终测试数见 VALIDATION.md。独立代理作静态及内存合成调用检查；浏览器交互由原实施代理验证，两者不混同。

去标识规则仍不能保证识别全部自由叙述姓名、地址及可重识别组合；输入与所有输出均需人工核查。原文计划整段勾选仅表示已核对，不意味着其中所有处置获准或已实施。应用没有经过临床有效性验证，不自动开具处方或替代机构病历审核。实际打印、各平台离线安装和用户 GitHub Actions 部署仍需相应环境验证。
