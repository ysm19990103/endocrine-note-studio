# 临床使用边界与核对要求

内分泌病历工作台将输入事实组织成文书草稿，并提供有限的鉴别讨论提示及工作清单。它使用可查看的本地规则，不使用远程大模型，也不能完成自由文本的完整语义理解。没有经过临床有效性验证，不能自动确诊、制定处方、签署医嘱或代替上级医师查房。

章节框架参考 [2010 年《病历书写基本规范》](https://www.nhc.gov.cn/wjw/gfxwj/201002/79d42b9c8b3f47ee91000d31de116784.shtml)。去标识化导出有意省略患者、医师真实身份和签名，不能作为完整、已签署病历直接归档；应在机构病历系统内据实补全并完成医师核签。模板格式本身不保证记录符合机构的全部要求。

## 事实与讨论分开

患者事实只能来自当前用户输入。来源资料用于设计字段和讨论框架，不能给当前患者补齐年龄、症状、检验数值或治疗。否认某病、家族史、既往史和待排诊断均应保留原有语义；关键词匹配不构成当前确诊。

初步诊断、鉴别方向和后续建议必须由医师逐项核对。支持与反对证据不足时，应写明缺口。未提供的阴性症状、正常体征、过敏史、妊娠状态、治疗反应和复查结论不能补成默认值。

## 新增检查结果

每项结果应核对采样日期和时间、标本类型、数值、单位、实验室参考范围、检测方法以及空腹、体位或刺激条件。发生单位不同、结果矛盾、检测方法变更或日期不明时，应先查原始报告，不能仅按输入顺序判断变化。

内分泌动态试验不能依赖一个结果或一个关键词解释。适应证、禁忌证、干扰药物、试验准备、执行环境、监测和停止条件均需由临床团队按实际方案核实。应用不生成可直接执行的药物剂量、停药时间或侵入性操作指令。

## 查房与治疗清单

查房草稿需要实际的查房时间、病情变化、检查结果和上级意见。没有实际意见时只能保留待补充提示或讨论草稿，不得写成已发生的医师指示。应用不生成真实签名，不证明告知同意、沟通或检查已经完成。

复选框表示使用者主动标记的工作进度。“完成”不等于医疗执行凭证，也不意味着该建议已被医师批准。重新生成计划后，应检查项目是否仍适合当前病情。

## 七个模块的范围

| 模块 | 需要保留的边界 |
| --- | --- |
| 甲状腺毒症 | 功能异常与病因分开；异常 FT4 不能单独确定 Graves 病 |
| 甲状腺结节 | 结节存在不说明良恶性；穿刺和随访需结合具体风险及尺寸 |
| 血糖异常 | 区分既往诊断、应激、药物及新发现异常；不能由孤立结果自动分型 |
| 原醛方向 | 高血压或低钾不自动确诊；需核对肾素、醛固酮、单位和采样条件 |
| 肾上腺功能不全方向 | 结合 ACTH、皮质醇时点及所有途径的激素暴露；不自动减停药 |
| GH / IGF-1 异常 | 结合临床表型、年龄适配范围和检测方法；不机械套用动态试验切点 |
| 高钙血症方向 | 先复核血钙与相关背景；恶性肿瘤相关指南不能代表所有高钙患者的治疗 |

以上是文书与证据核对边界，不构成独立诊疗方案。未覆盖的疾病可以记录原始事实，但不能把“没有相关提示”解读为已排除疾病。

## 正式使用前核对

1. 所有身份信息已由使用者复核，且输入与导出符合机构要求。
2. 当前患者的每条事实能回到实际入院记录、查房记录或原始报告。
3. 缺失、否定、疑诊、既往和家族史没有被改写成新的肯定事实。
4. 新旧结果、单位和采样背景清楚，矛盾结果已经核实。
5. 诊断、鉴别与计划反映真实临床判断；上级意见和签署由实际医师完成。
6. 危急病情已优先进行床旁评估和处理，没有等待本工具生成完整文书。

临床机构如需接入电子病历、病例数据库或在线模型，应另行开展权限、日志、数据安全及临床验证评估；当前版本不包含这些集成。
